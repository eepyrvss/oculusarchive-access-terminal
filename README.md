## ABOUT

The access terminal for the **Oculus Squad Archives**, a fan-made archive for the 7th Reconnaissance Detachment, a fictional special operations squad created for *Project: APEX*.

Some files in the archive are classified. This terminal is the lock.

## HOW IT WORKS

1. Read the archive.
2. Collect the three access codes.
3. Enter all three. Wrong codes are rejected; the right ones open the file.

Not everything in a file is meant to be seen at first glance.
